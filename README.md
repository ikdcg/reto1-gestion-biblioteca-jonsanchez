# Gestión de Biblioteca

## Descripción

Este proyecto consiste en crear un programa en Python para gestionar una biblioteca.
Permite controlar los libros, los socios y los préstamos.

## Funciones principales

- Mostrar libros y socios.
- Buscar libros por título.
- Consultar los libros disponibles.
- Prestar y devolver libros.
- Añadir nuevos libros y socios.
- Guardar los cambios al salir.

## Tecnologías utilizadas

- Python
- Git y GitHub
- Archivos TXT

## Cómo ejecutar el programa

Para iniciar el programa, hay que ejecutar:

python main.py

## Organización

El proyecto está dividido en varias carpetas para tener el código organizado:

- `modelo`: clases Libro y Socio.
- `funciones`: funciones del programa.
- `datos`: archivos donde se guardan los libros y socios.
- `errores`: excepciones personalizadas.

## Posibles mejoras

En el futuro se podrían añadir algunas mejoras al programa, como:

- Crear un sistema de usuarios y contraseñas.
- Añadir fechas límite para devolver los libros.
- Permitir modificar o eliminar libros y socios.
